# Security reporting

BreakALeg is a security review aid, not a security guarantee. Its bounded runner is not a sandbox for the agent. Use only against systems you own or are authorized to test.

This initial source package does not yet have a published repository or verified maintainer contact. Before public launch, the maintainer must enable a private reporting channel and publish that channel here. No email address or repository URL is assumed.

If the hosting repository offers GitHub private vulnerability reporting, use its **Security → Report a vulnerability** action. If no private channel is available, ask the maintainer for one without posting vulnerability details publicly.

Include the affected version, minimal synthetic reproduction, impact, and relevant platform/runtime versions. Omit real tokens, customer data, private reports, and production exploit payloads. Issues involving runner scope bypass, credential disclosure, or incorrect confirmed findings are particularly useful.

Only v0.1 is currently defined. There is no promised response-time SLA or supported older-version window.
