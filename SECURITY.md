# Security reporting

BreakALeg is a security review aid, not a security guarantee. Its bounded runner is not a sandbox for the agent. Use only against systems you own or are authorized to test.

GitHub private vulnerability reporting is enabled for [notsocj/break-a-leg](https://github.com/notsocj/break-a-leg).

Use **[Report a vulnerability](https://github.com/notsocj/break-a-leg/security/advisories/new)** to contact the maintainer privately. Do not disclose vulnerabilities or sensitive assessment outputs in a public issue. If the reporting form is unavailable, ask the maintainer for a private channel without including exploit details.

Include the affected version, minimal synthetic reproduction, impact, and relevant platform/runtime versions. Omit real tokens, customer data, private reports, and production exploit payloads. Issues involving runner scope bypass, credential disclosure, or incorrect confirmed findings are particularly useful.

Use the latest 0.1.x version for fixes. There is no promised response-time SLA or maintenance commitment for older versions.
